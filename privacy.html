개인정보처리방침

시행일: 2026-11-01

  • 누가 쓰나 — Cockpit은 개발자 본인만 쓰는 개인용 도구입니다.
  • 무엇에 접근하나 — Google Tasks(https://www.googleapis.com/auth/tasks) 하나뿐입니다. 본인 계정의 할 일 목록만 읽고 고칩니다.
  • 어디에 두나 — 받은 데이터와 로그인 토큰은 개발자 본인의 컴퓨터 안에만 저장합니다.
  • 누구와 나누나 — 제3자에게 팔거나 넘기지 않으며, 광고에 쓰지 않습니다.
  • Google API 데이터 — Google API에서 받은 정보의 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.
  • 그만두기 — Google 계정 → 보안 → 타사 액세스에서 언제든 권한을 해제할 수 있습니다.

Privacy Policy (English)

Cockpit is a personal tool used only by its developer. It accesses only Google Tasks for the developer's own account. Data and tokens are stored only on the developer's own computer, are never sold or shared with third parties, and are not used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account security settings.
