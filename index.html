Cockpit

Cockpit은 한 사람이 자기 업무를 정리하려고 만든 개인용 도구입니다. 일반에 제공하는 서비스가 아니며, 다른 사용자를 받지 않습니다.

Google 계정에는 Google Tasks 권한 하나만 요청합니다. 본인의 할 일 목록 하나(「Cockpit 피드백」)를 읽고 정리하는 데만 씁니다.

Cockpit is a personal productivity tool used only by its developer. It requests access to Google Tasks solely to read the developer's own task list.
